Hi, I'm Stefan.

I work as a software engineer and data analyst, and I write here about how I use artificial intelligence in my daily work — mostly in my open-source projects hosted on GitHub.

My view on it is a sober one: the scope and pace of this work can no longer be sustained without AI-assisted tools. To me they are neither an experiment nor a matter of taste, but part of the basic toolkit — as ordinary as version control or automated tests. So the interesting question isn't whether to use them, but how: which tasks to hand over, where to measure, and how to keep the results verifiable. That's what this blog is about.

I run Fedora Linux and Debian Linux. I program in Kotlin, Julia, Wolfram (Mathematica), Python, Java, Ruby, and Rust; for Android apps I use Jetpack Compose and Ktor. VSCodium and Android Studio are my preferred development environments, and for data analysis I use JupyterLab with Julia. For AI-assisted development, my tool of choice is Claude Code.
