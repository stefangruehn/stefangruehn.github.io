Four posts about a single observation: this blog does not only describe how it comes about.
It changes it.

The first shows the case where that first became visible: a post about my keyboard shortcuts changed the file my agent reads at the start of every session.
The second counts how much of this blog is about this blog, and where the circle stops.
The third measures the coupling — 57 commits, 39 new post files, 86 changes to existing ones, the smallest of them two.
The fourth asks what happens when a loop like that works well, and ends on three numbers allowed to be wrong in four weeks.

[Self-Similarity](/series/self-similarity/) supplied the vocabulary: recursion, coupling, amplification, chaotic behaviour.
That series was about agents.
This one is about what they leave behind.
