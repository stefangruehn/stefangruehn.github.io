Four posts about a single observation: this blog does not only describe how it comes about.
It changes it.

The first shows the case where that first became visible: a post about my keyboard shortcuts changed the file my agent reads at the start of every session.
The second counts how much of this blog is about this blog, and where the circle stops.
The third measures the coupling: 57 commits, 39 new post files, 86 changes to existing ones, the smallest of them two.
The fourth asks what happens when a loop like that works well, and ends on three numbers allowed to be wrong in four weeks.

[Self-Similarity](/series/self-similarity/) supplied the vocabulary: recursion, coupling, amplification, chaotic behaviour.
That series was about agents.
This one is about what they leave behind.

## Whether this is for you

The path from left to right is ordinary: you work, you write about it, and at some point a rule is set.

**The arrow going back** is the reason to read.
The post does not stop at describing, it changes the file the next session runs on, and with it the work the next post comes out of.
Part 1 shows the case where that first became visible, part 3 measures how tight the coupling is: 57 commits, 86 changes to existing posts, the smallest of them two files.

> If you enjoy watching a text act back on the person who wrote it, you are in the right place.
> If commit counts and file lists spoil your evening, less so.

**The dashed arrow** is the uncomfortable half.
A feedback loop that runs well supplies its own material, and then it lacks exactly what its theories could break against.
Part 4 sets three expectations against that, all of them allowed to be wrong in four weeks.

Nothing is assumed beyond a blog or a project that has run long enough to have a history of its own.
Part 3 works with commit counts, the other three with none at all.
If you only read one part, start with the second: it says where the circle stops.
